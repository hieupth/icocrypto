# ICO LANDPAGE

Landing page framework built with **Next.js (App Router)** and **TypeScript**, inspired by the design of [**Ico Crypto**](https://themeforest.net/item/ico-crypto-bitcoin-cryptocurrency-landing-page-html-template/21405614) HTML template.

## ✨ Features
- **Next.js App Router** with static export for SEO optimization.  
- **Internationalization (i18n)** with locale-prefixed routes using `next-intl`.  
- **Bootstrap 5 compatibility** — HTML structure and classes match purchased theme CSS . 
- **Reusable components**: use atomic design pattern. 
- **Responsive and mobile-first**  
- **SEO ready**: metadata, canonical/alternate links.

## 🌐 Internationalization

- All routes are locale-prefixed (e.g., `/en`, `/vi`, `/jp`).  
- Translations live under `src/mdb/messages/{locale}.json`.  
- Update `config/locale.json` to add or remove supported languages.
